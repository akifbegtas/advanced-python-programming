# Advanced Python Programming (ENG3050)

Interactive study notes, reference guides, exercises, and practice questions for **Advanced Python Programming (ENG3050)**.

## 🚀 Live Demo
Access the live version on GitHub Pages:
**[https://akifbegtas.github.io/advanced-python-programming/](https://akifbegtas.github.io/advanced-python-programming/)**

## 📚 Topics Covered
- **Week 2 & 3:** Advanced Python Features, Comprehensions, Lambda Functions, Built-in Higher-Order Functions
- **Week 4:** Object-Oriented Programming (OOP), Dunder Methods, Inheritance & Polymorphism
- **Week 5:** Error & Exception Handling, Custom Exceptions, Defensive Programming
- **Week 6:** File I/O, Serialization (JSON, Pickle, HDF5), NumPy Data Pipelines
