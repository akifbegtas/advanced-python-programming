# Advanced Python Programming (İleri Python Programlama)

ENG3050 ders PDF’lerine dayanan interaktif çalışma rehberi. **Anlatımlar, sorular ve çözümler Türkçedir.** Başlıklar ve teknik terimler İngilizce, Türkçe karşılıkları parantez içindedir.

## Live Demo (Canlı Görünüm)

[Çalışma rehberini aç](https://akifbegtas.github.io/advanced-python-programming/)

## Course Content (Ders İçeriği)

- **Week 2 & 3 (Hafta 2 ve 3):** Yazılım geliştirme yaşam döngüsü, gereksinimler, analiz, mimari, test, yayımlama, bakım; kusur maliyeti, izlenebilirlik, kapasite ve güvenilirlik hesapları.
- **Week 4 (Hafta 4):** Python hata türleri; sensör uyarıları, direnç hesabı, ağırlıklı ortalama ve metin verilerini işleme.
- **Week 5 (Hafta 5):** Tür ve girdi doğrulama, birimler, istisna akışı, try/except/else, hata izleri ve hata ayıklayıcı.
- **Week 6 (Hafta 6):** Dosya yolları ve kipleri, TXT, CSV, Pandas, Pickle, JSON, HDF5; eksik veri, parçalı işleme ve sayısal hassasiyet.

## Study Tools (Çalışma Araçları)

- 28 kapsamlı konu özeti ve Python örnekleri.
- 37 açıklamalı test sorusu: tek seçim, çoklu seçim ve doğru/yanlış.
- PDF örneklerine dayanan 20 klasik soru, açılabilir çözümler ve cevap alanları.
- 20 soruluk, 25 dakikalık deneme sınavı.
- Tekrar kartları, mühendislik hesaplayıcıları ve konu arama.
- Tarayıcıda yerel ilerleme kaydı; JSON yedeği dışa/içe aktarma.
- Mobil görünüm ve yazdırma desteği.

## Local Use (Yerel Kullanım)

`index.html` dosyasını tarayıcıda açman yeterli. İnternet veya ek kurulum gerekmez. İstersen klasörde yerel sunucu başlatabilirsin:

```bash
python3 -m http.server 8000
```

Python kodları okuma ve çalışma örnekleridir; HTML içinde çalıştırılmaz. İlerleme tarayıcıda saklanır, farklı cihazlar arasında eşitlenmez. Devam eden deneme, sayfa yenilenince korunmaz.
